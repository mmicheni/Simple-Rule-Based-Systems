ℹ️ Knowledge-Based System Details

            
            

                
System Architecture & Design

                
This application implements a complete Knowledge-Based System (KBS) tailored for personal financial planning advice. The architecture separates domain facts and validation rules from the evaluation execution code:

                
                

                    

                        
1. Knowledge Base

                        
All declarative knowledge rules are defined in a structural JSON file (knowledge_base.json). Each rule represents conditional statements matching fact values and triggering subsequent fact derivations or user advice blocks.

                    

                    

                        
2. Inference Engine

                        
Implements a custom **Forward-Chaining** reasoning cycle. Starting with user inputs, the engine repeatedly fires rules that evaluate to True. Derivation rules inject new intermediate facts, causing the engine to execute subsequent cycles until no further facts can be derived.

                    

                    

                        
3. Knowledge Acquisition

                        
Incorporates validation procedures. Before saving any rule, the system validates the syntax, screens for duplicates, and builds a dependency map to check for circular paths, protecting the reasoning loop from logical crashes.
